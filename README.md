# X箇条書き文字数チェッカー

<img src="icon128.png" width="128" alt="X箇条書き文字数チェッカー">

テキストを選択するだけで、各行の文字数を自動でチェックして色分けハイライト表示するChrome拡張機能。
X（Twitter）の箇条書き投稿やスプレッドシート、Notionなど、あらゆるWebページで使えます。

## ✨ 機能

- 📝 **行ごとに文字数を表示**: 各行の右横にかわいいバッジで文字数表示
- 🎨 **色分けハイライト**: 文字数に応じてパステルカラーで自動色分け
  - **15文字以内** → 水色（理想的な長さ）
  - **16-17文字** → ピーチ（少し長め）
  - **18文字以上** → ピンク（長い）
- 🔢 **合計文字数表示**: 選択範囲全体の合計文字数を「○○文字 / 140」で表示
- 📏 **半角0.5文字計算**: 全角1文字、半角0.5文字で正確にカウント
- 🌐 **すべてのWebページで動作**: X、Notion、Googleスプレッドシート、どこでもOK

## 🚀 インストール方法

### 方法1: GitHubからダウンロード（推奨）

1. このリポジトリをダウンロード
   - 緑の「Code」ボタン → 「Download ZIP」
   - またはターミナルで: `git clone https://github.com/あなたのユーザー名/x-char-counter.git`

2. Chromeで拡張機能を読み込む
   - Chromeを開く
   - アドレスバーに `chrome://extensions/` と入力
   - 右上の「**デベロッパーモード**」をONにする
   - 「**パッケージ化されていない拡張機能を読み込む**」をクリック
   - ダウンロードしたフォルダを選択

3. 完了！
   - ツールバーにかわいいパステルカラーのアイコンが表示されます

## 📖 使い方

1. 任意のWebページで**テキストを選択**（マウスドラッグ）
2. 自動的にハイライト + 各行の文字数バッジ + 合計文字数が表示される
3. **Escキー**または別の場所をクリックで解除

### 使用例

```
この行は14文字です        [14文字]（水色）
この行は17文字なので黄色    [17文字]（ピーチ）
この行は20文字を超えるのでピンク [22文字]（ピンク）
                           [合計: 53文字 / 140]
```
